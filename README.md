# LegalAI

https://drive.google.com/drive/folders/1o-SQW3EfJiQexi0UdQpDtcrRRTtK_vR1 

LegalAI es una plataforma web orientada a apoyar a profesionales del derecho en la gestión y análisis de información jurídica.

El proyecto busca centralizar expedientes, clientes y documentos legales en un solo entorno, incorporando herramientas de inteligencia artificial que faciliten la consulta y comprensión de la información almacenada.

## Propósito

En el trabajo jurídico es común manejar grandes cantidades de documentos, expedientes e información relacionada con distintos clientes y casos.

LegalAI busca facilitar este proceso mediante una plataforma que permita organizar la información y aprovechar inteligencia artificial como herramienta de apoyo para consultar documentos y obtener información relevante de manera más rápida.

La plataforma está diseñada como un sistema de asistencia. Las respuestas generadas por inteligencia artificial sirven como apoyo y no reemplazan el análisis ni el criterio profesional del abogado.

## ¿Qué permite hacer LegalAI?

LegalAI permite:

- Registrar y administrar usuarios.
- Gestionar clientes.
- Crear y administrar expedientes.
- Registrar y cargar documentos PDF.
- Extraer el contenido textual de documentos.
- Preparar documentos para su análisis mediante inteligencia artificial.
- Realizar consultas sobre los documentos almacenados.
- Mantener conversaciones relacionadas con los expedientes.
- Utilizar información relevante de los documentos como contexto para las respuestas de IA.
- Consultar las fuentes utilizadas en las respuestas.
- Descargar documentos almacenados.
- Mantener un registro de determinadas acciones realizadas dentro del sistema.

## Inteligencia Artificial

LegalAI incorpora inteligencia artificial para trabajar con la información contenida en los documentos del usuario.

Los documentos pueden ser procesados y divididos en fragmentos que posteriormente son utilizados para localizar información relacionada con una consulta.

De esta manera, el sistema puede generar respuestas utilizando como contexto los documentos asociados al usuario y mostrar las fuentes relacionadas con la información utilizada.

Esto permite que la inteligencia artificial funcione como una herramienta de apoyo sobre documentación concreta, en lugar de depender únicamente de conocimiento general.

## Seguridad y privacidad

La plataforma busca mantener separada la información perteneciente a cada usuario.

Los clientes, expedientes, documentos y conversaciones están asociados a sus respectivos propietarios, evitando que un usuario pueda acceder directamente a información perteneciente a otro.

El acceso a las funcionalidades protegidas se realiza mediante autenticación.

## Tecnologías principales

El backend de LegalAI ha sido desarrollado principalmente utilizando:

- Java 21
- Spring Boot
- Spring Security
- PostgreSQL
- Maven
- JWT
- Swagger / OpenAPI
- Gemini
- PDFBox
- pgvector

## Estado del proyecto

LegalAI es un proyecto académico actualmente orientado al desarrollo y validación de una plataforma de apoyo para profesionales del derecho.

El sistema cuenta con funcionalidades para la gestión de usuarios, clientes, expedientes y documentos, además del procesamiento de documentos y herramientas de consulta apoyadas por inteligencia artificial.

## Objetivo

El objetivo de LegalAI es demostrar cómo tecnologías modernas de desarrollo de software e inteligencia artificial pueden integrarse para facilitar la gestión de información jurídica, manteniendo al profesional del derecho como responsable final de la interpretación y toma de decisiones.
